Why check a GSTIN before invoicing?

A wrong GSTIN on a B2B invoice means your client can't claim input tax credit, and the invoice usually has to be cancelled or amended. The state code also decides whether you charge CGST + SGST or IGST, so a typo there puts the wrong tax on the bill.

Questions

How is the GSTIN check character calculated?

Each of the first 14 characters is turned into a number (0–9 stay as they are, A–Z become 10–35). Numbers in even positions are doubled, each product is split into a quotient and remainder by 36 and added up, and the check character is whatever brings the sum to a multiple of 36.

Can a valid-looking GSTIN still be wrong?

Yes. The check confirms the number is well formed, not that it was ever issued or is still active. Search it on the GST portal if you need to confirm the registration.

Is a GSTIN the same as a PAN?

No, but every GSTIN contains a PAN in characters 3 to 12. One PAN can have several GSTINs: one per state where the business is registered, and more than one in a state if it has separate registrations there.
